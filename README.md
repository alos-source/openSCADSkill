# OpenSCAD Vibecoding Agent for Google Antigravity

Ein spezialisierter Agent/Skill für Google Antigravity, der parametrischen OpenSCAD-Code schreibt, Vorschaubilder über die CLI rendert und visuell iteriert.

## System-Voraussetzungen
- OpenSCAD muss auf dem Rechner installiert und im System-PFAD (`PATH`) erreichbar sein.

## Installation
Kopiere den Ordner `.agents/` in deine eigene Antigravity-Arbeitsumgebung (Workspace).

## Benutzung
Frage Antigravity einfach nach einem 3D-Modell:
> "Erstelle mir eine Halterung für ein ESP32-Board mit M3 Schraublöchern."
