# Validate Model

Use this skill to leave a short review checklist for print readiness and manual verification.

## Workflow
1. Run `ai/shared/scripts/validate-model.ps1 -InputFile <path>`.
2. Review the generated checklist.
3. Update it after visual inspection or after printing.

## Output
- A text checklist is written next to the source file.
